# Od portfolio do 9 000 zł na rękę

Interaktywny przewodnik po 8 ścieżkach zarabiania w contencie i social media (Kraków i praca zdalna, dane z września 2026): dopasowanie ścieżki, plan krok po kroku, kalkulator dochodu na rękę, checklista na pierwszy miesiąc i oferty pracy z licznikiem dni.

## Jak opublikować na GitHub Pages (ok. 3 minuty, przez przeglądarkę)

1. Na github.com kliknij **New repository**, nazwij je np. `droga-9000`, zaznacz **Public** i kliknij **Create repository**.
2. Kliknij **uploading an existing file**, przeciągnij plik `index.html` (i ten `README.md`), potem **Commit changes**.
3. Wejdź w **Settings → Pages**. W **Source** wybierz **Deploy from a branch**, gałąź **main**, folder **/ (root)**, kliknij **Save**.
4. Po 1–2 minutach strona będzie pod adresem `https://<twoja-nazwa>.github.io/droga-9000/`.

Jeśli wysyłasz pliki z terminala, ustaw w git adres noreply z GitHuba (**Settings → Emails**), żeby w historii commitów nie zapisał się prywatny ani służbowy e-mail.

## Co warto wiedzieć

- Strona to jeden plik HTML bez zewnętrznych skryptów; z internetu pobiera tylko czcionki Google Fonts.
- Postęp checklist zapisuje się w przeglądarce osoby, która ją otwiera (localStorage), i nie trafia nigdzie dalej.
- Dane są aktualne na 27.09.2026. Oferty pracy wygasają, więc przed aplikacją sprawdź ogłoszenie.
- Kalkulator upraszcza podatki (ryczałt 15%, bez ulgi dla młodych i PPK) i nie jest poradą podatkową.
